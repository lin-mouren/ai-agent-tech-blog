# Donating the Model Context Protocol and establishing the Agentic AI Foundation

**December 9, 2025** | Anthropic

## Overview

Anthropic donated the Model Context Protocol (MCP) to the Agentic AI Foundation (AAIF), a directed fund under the Linux Foundation, co-founded by Anthropic, Block, and OpenAI, with support from Google, Microsoft, Amazon Web Services (AWS), Cloudflare, and Bloomberg.

This donation ensures MCP remains a neutral, open standard for the long term.

## About MCP

The Model Context Protocol (MCP) is a standard way to connect AI models and agents to tools and data. Since its launch in November 2024, MCP has seen rapid adoption:
- The community has built **thousands of MCP servers**
- SDKs are available for all major programming languages
- The industry has adopted MCP as the de-facto standard for connecting agents to tools and data

MCP was created at Anthropic by David Soria Parra and Justin Spahr-Summers.

## Why Donate to the Linux Foundation?

Donating MCP to the Linux Foundation through the AAIF:
- Ensures community-driven governance
- Makes MCP a neutral, open standard no single company controls
- Fosters innovation across the agentic AI ecosystem
- Ensures foundational technologies remain neutral, open, and community-driven

## About the Agentic AI Foundation (AAIF)

The AAIF is a directed fund under the Linux Foundation co-founded by Anthropic, Block, and OpenAI, with support from Google, Microsoft, AWS, Cloudflare, and Bloomberg.

The AAIF aims to ensure agentic AI evolves:
- Transparently
- Collaboratively  
- In the public interest

Through strategic investment, community building, and shared development of open standards.

## Governance

MCP's governance model remains unchanged:
- Project maintainers continue to prioritize community input
- Transparent decision-making is maintained
- AAIF structure is funded through a "directed fund" with membership dues
- Project roadmaps are set by technical steering committees—no single member gets unilateral say

## Founding Projects

- **MCP** by Anthropic — protocol for connecting agents to tools and data
- **goose** by Block — open source agent framework
- **AGENTS.md** by OpenAI — project-specific agent instructions format
