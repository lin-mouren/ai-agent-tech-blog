Today we're announcing that the [Interactions API](https://ai.google.dev/gemini-api/docs/interactions) has reached general availability and is now our primary API for interacting with Gemini models and agents. We launched its public beta in December 2025, and it has quickly become developers’ favorite way to build applications with Gemini.

With this GA release, the API now has a stable schema and we also added major new capabilities that developers asked for, including Managed Agents, background execution, Gemini Omni (soon) and more. All of our documentation now defaults to Interactions API and we are working with ecosystem partners to make it the default interface across 3P SDKs and Libraries.

## The simplest way to build with Gemini

Whether you're calling a model or running an agent, the Interactions API gets you there in a few lines of code. Pass a model ID for inference, an agent ID for autonomous tasks, set `background=True` for anything long-running.

```py
from google import genai

client = genai.Client()

# Talk to a model
interaction = client.interactions.create(
    model="gemini-3.5-flash",
    input="Explain quantum entanglement simply.",
)

# Run an agent
interaction = client.interactions.create(
    agent="antigravity-preview-05-2026",
    input="Plot the growth of solar energy generation globally and make some slides in HTML.",
    environment="remote",
)
```

## Key updates since December

- [**Managed Agents**](https://blog.google/innovation-and-ai/technology/developers-tools/managed-agents-gemini-api/) **:** A single API call provisions a remote Linux sandbox where an agent can reason, execute code, browse the web and manage files. The [Antigravity agent](https://ai.google.dev/gemini-api/docs/antigravity-agent) ships as the default, and you can [define your own custom agents](https://ai.google.dev/gemini-api/docs/custom-agents) with instructions, skills and data sources.
- [**Background execution**](https://ai.google.dev/gemini-api/docs/interactions#long-running-and-background-tasks) **:** Set background=True on any call. The server runs the interaction asynchronously.
- [**Tool improvements**](https://ai.google.dev/gemini-api/docs/tool-combination) **:** Mix built-in tools , such as [Google Search](https://ai.google.dev/gemini-api/docs/google-search), [Google Maps](https://ai.google.dev/gemini-api/docs/maps-grounding) with your own functions in one request. Tool results can now [return images alongside text](https://ai.google.dev/gemini-api/docs/function-calling).
- [**Deep Research**](https://ai.google.dev/gemini-api/docs/deep-research) **upgrades:** Two new agent versions (speed vs. depth), collaborative planning, native charts and infographics, and multimodal grounding with images, PDFs and audio.
- **Media generation:** [Image generation](https://ai.google.dev/gemini-api/docs/image-generation) with Nano Banana 2 and Google Image Search grounding, [music](https://ai.google.dev/gemini-api/docs/music-generation) with Lyria 3, and [expressive speech](https://ai.google.dev/gemini-api/docs/speech-generation) with multi-speaker TTS.
- [**From Roles to Steps**](https://ai.google.dev/gemini-api/docs/interactions-breaking-changes-may-2026) **:** Simplified schema where every action (user\_input, thought, function\_call, model\_output, etc.) is its own typed step, replacing the old role structure.
- **Cost and developer optimizations:** [Flex and Priority tiers](https://ai.google.dev/gemini-api/docs/flex-inference) let you optimize for cost or latency (Flex offers 50% cost reduction). Errors now pinpoint the exact field. Past interactions are [retrievable](https://ai.google.dev/gemini-api/docs/interactions) with 55-day retention on the paid tier.

## The new standard for development

The Interactions API is now the default for Google AI Studio, the Gemini API, and all our [documentation](https://ai.google.dev/gemini-api/docs), which includes a toggle to switch snippets back to the legacy format. We recommend using the Interactions API for all new projects and applications.

While the legacy generateContent API remains fully supported and will continue to receive new mainline Gemini models for the foreseeable future, we expect frontier capabilities for long-running models and agents to increasingly land exclusively on the Interactions API. This is because it is designed from the ground up for stateful, agentic workflows. We have published a [migration guide](https://ai.google.dev/gemini-api/docs/migrate-to-interactions) to help you transition at your own pace.

## An agent-first ecosystem

Most developers are now using coding agents (such as Antigravity) to build applications. To make it easier for agents to stay up to date with the latest API patterns, we built the [**gemini-interactions-api Skill**](https://ai.google.dev/gemini-api/docs/coding-agents#gemini-interactions-api). It injects best-practice patterns for Interactions API development into your agent's context (streaming, function calling, structured output, Deep Research and more).

```py
npx skills add google-gemini/gemini-skills --skill gemini-interactions-api
```

## Get started

The Interactions API is available through the [Python](https://pypi.org/project/google-genai/) and [JavaScript](https://www.npmjs.com/package/@google/genai) SDKs. If you're already building with one of our supported partners, [LiteLLM](https://docs.litellm.ai/docs/interactions), [Eigent](https://www.eigent.ai/use-cases/eigent-gemini-managed-agents) or [Agno](https://docs.agno.com/models/providers/native/google/gemini-interactions), you can start using their Interactions API integrations today.

Grab your API key from [Google AI Studio](https://aistudio.google.com/) and follow the [Interactions API documentation](https://ai.google.dev/gemini-api/docs/interactions) to get started. If you’re migrating from generateContent, our [migration guide](https://ai.google.dev/gemini-api/docs/migrate-to-interactions) maps every field to the new schema. You can also view the full [API Reference](https://ai.google.dev/api/interactions-api).

The Interactions API was built based on developer feedback, and that focus won't change with general availability. Tell us what you need on the [developer forum](https://discuss.ai.google.dev/).
