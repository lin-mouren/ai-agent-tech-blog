# Gemini 2.5: Our most intelligent models are getting even better

May 20, 2025 | 7 min read | Tulsee Doshi

Gemini 2.5 Pro continues to be loved by developers as the best model for coding, and 2.5 Flash is getting even better with a new update. We're also bringing new capabilities to our models, including Deep Think, an experimental enhanced reasoning mode for 2.5 Pro.

## 2.5 Pro performs better than ever

In addition to its strong performance on academic benchmarks, the new 2.5 Pro is now leading the popular coding leaderboard, WebDev Arena, with an ELO score of 1415. It's also leading across all leaderboards of the LMArena, which evaluates human preference in various dimensions. With its 1 million-token context window, 2.5 Pro has state-of-the-art long context and video understanding performance.

Since incorporating LearnLM, our family of models built with educational experts, 2.5 Pro is also now the leading model for learning.

### Deep Think

Through exploring the frontiers of Gemini's thinking capabilities, we're starting to test an enhanced reasoning mode called Deep Think that uses new research techniques enabling the model to consider multiple hypotheses before responding.

2.5 Pro Deep Think gets an impressive score on 2025 USAMO, currently one of the hardest math benchmarks. It also leads on LiveCodeBench, a difficult benchmark for competition-level coding, and scores 84.0% on MMMU, which tests multimodal reasoning.

## An even better 2.5 Flash

2.5 Flash is our most efficient workhorse model designed for speed and low-cost—and it's now better across many dimensions. It's improved across key benchmarks for reasoning, multimodality, code and long context while getting even more efficient, using 20-30% less tokens in our evaluations.

## New Gemini 2.5 capabilities

### Native audio output
The Live API is introducing a preview version of audio-visual input and native audio out dialogue, enabling more natural and expressive conversational experiences.

### Computer use
We're bringing Project Mariner's computer use capabilities into the Gemini API and Vertex AI.

### Better security
We've significantly increased protections against security threats, like indirect prompt injections.

## Enhanced developer experience

Thought summaries, thinking budgets, and MCP support are being added to improve the developer experience when building with Gemini models.
