# OpenAI co-founds the Agentic AI Foundation under the Linux Foundation

**December 9, 2025** | OpenAI

AAIF aims to advance open-source agentic AI with the donation of standards including OpenAI's AGENTS.md.

## Overview

OpenAI is co-founding the Agentic AI Foundation (AAIF) under the Linux Foundation, alongside Anthropic and Block, and with the support of Google, Microsoft, AWS, Bloomberg, and Cloudflare. The AAIF is designed to provide neutral stewardship for open, interoperable infrastructure as agentic AI systems move from experimentation into real-world production.

As part of this effort, OpenAI is contributing **AGENTS.md**—a simple, open format for providing agents with project-specific instructions and context—to the foundation.

## Why Open Standards Matter

Developers are rapidly adopting AI to build more capable agentic systems—from coding assistants to workflow automation and customer service agents. The transition from experimental agents to real-world systems works best with open standards that help make them interoperable.

Open standards:
- Make agents safer, easier to build, and more portable across tools and platforms
- Help prevent ecosystem fragmentation as agentic AI matures
- Enable trustworthy infrastructure for production deployment

## About AGENTS.md

AGENTS.md is a lightweight Markdown file designed to live alongside README.md. It offers a simple, interoperable standard that gives AI coding agents a consistent source of project-specific guidance needed to operate reliably across different repositories and toolchains.

Since its release in August 2025, AGENTS.md has been adopted by more than **60,000 open-source projects** and agent frameworks including Amp, Codex, Cursor, Devin, Factory, Gemini CLI, GitHub Copilot, Jules, and VS Code.

## OpenAI's Contributions to the Open Agentic Ecosystem

- **Agents SDK** and **Apps SDK** for building agentic systems
- **Agentic Commerce Protocol** for agent-based transactions
- **gpt-oss models** and **Codex CLI** for open-source development
- Codex has helped merge more than **2 million public pull requests on GitHub**
- Early adoption and contribution to Model Context Protocol (MCP)

## Founding Members

AAIF is established by:
- **Co-founders**: OpenAI, Block, Anthropic
- **Supporting members**: Google, Microsoft, Amazon, Bloomberg, Cloudflare

The AAIF operates as a directed fund under the Linux Foundation, ensuring no single company controls the direction of foundational infrastructure.

## Foundation Projects

- **AGENTS.md** by OpenAI — project-specific agent instructions
- **Model Context Protocol (MCP)** by Anthropic — standard for connecting models and agents to tools
- **goose** by Block — open-source agent framework
