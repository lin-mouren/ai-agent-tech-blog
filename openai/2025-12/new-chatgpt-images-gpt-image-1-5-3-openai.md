# The new ChatGPT Images is here

**December 16, 2025** | OpenAI

## Overview

OpenAI released a new version of ChatGPT Images, powered by a new flagship image generation model (GPT-Image-1.5). The update offers:

- Precise edits while keeping details intact
- Image generation up to 4x faster
- A new dedicated Images feature within ChatGPT

The new Images model rolls out in ChatGPT for all users, and is available in the API as **GPT Image 1.5**.

## Key Improvements

### Precise Edits That Preserve What Matters

When users ask for edits to an uploaded image, the model adheres to intent more reliably—down to small details—changing only what is asked for while keeping elements like lighting, composition, and people's appearance consistent across inputs, outputs, and subsequent edits.

### Editing Capabilities
- Adding, subtracting, combining, blending, and transposing elements
- Changes without losing what makes the image special

### Creative Transformations
- Changes and adds elements—like text and layout—to bring ideas to life
- Preserves important details while supporting intricate concept changes

### Instruction Following
- More reliably follows complex instructions vs GPT Image 1.0
- Enables more precise edits and intricate original compositions

### Text Rendering
- Handles denser and smaller text

## GPT Image 1.5 in the API

GPT Image 1.5 in the API delivers all the same improvements as ChatGPT Images:
- Stronger at image preservation and editing than GPT Image 1
- More consistent preservation of branded logos and key visuals across edits
- Image inputs and outputs are now **20% cheaper** compared to GPT Image 1
- Better suited for marketing, brand work, and ecommerce product catalog generation

## Availability

The new ChatGPT Images model is rolling out to all ChatGPT users and API users globally. It works across models, so users don't need to select anything to use it. The original version of ChatGPT Images remains available as a custom GPT.
