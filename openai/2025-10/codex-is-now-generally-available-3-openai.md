# Codex is now generally available

We're announcing the general availability of Codex and three new features that make it even more useful for engineering teams:

- **A new Slack integration:** Delegate tasks or ask questions to Codex directly from a team channel or thread.
- **Codex SDK:** Embed the same agent that powers the Codex CLI into your own workflows, tools, and apps.
- **New admin tools:** With environment controls, monitoring, and analytics dashboards, ChatGPT workspace admins now have more visibility and control.

Since the Codex cloud agent launched in research preview in May, Codex has steadily evolved into a more reliable and capable coding collaborator. You can now work with it everywhere you code—in your editor, terminal, and the cloud. Daily usage of Codex has grown by more than 10x since early August, and GPT-5-Codex is one of our fastest growing models ever, serving over 40 trillion tokens in the three weeks since launch.

Codex is now used by developers all over the world, from startups like Duolingo and Vanta to large enterprises like Cisco and Rakuten. Inside OpenAI, nearly all engineers use Codex today. They merge 70% more pull requests each week, and Codex automatically reviews almost every PR to catch critical issues before they reach production.

## Codex in Slack

Tag @Codex in a Slack channel or thread and it will automatically gather the context it needs from the conversation, choose the right environment, and answer with a link to the completed task in Codex cloud.

## Codex SDK

With the Codex SDK, you can bring the same agent into your own engineering workflows and apps with just a few lines of code. The SDK is available for TypeScript today, with more languages coming soon.

## New admin features

ChatGPT admins can now edit or delete Codex cloud environments, enforce safer defaults, and monitor actions taken by Codex. New analytics dashboards help admins track usage across the CLI, IDE, and web.

## Codex at work

At Cisco, engineers are using Codex to speed up the review of complex pull requests, reducing review times by up to 50%. At Instacart, the Codex SDK is integrated with Olive, their background coding agent platform, to automate tech debt cleanup.

## Availability

The Slack integration and Codex SDK are available to developers on ChatGPT Plus, Pro, Business, Edu, and Enterprise plans starting today.
